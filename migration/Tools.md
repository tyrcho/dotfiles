Tools to install on the new laptop, and how each one gets its config back. "Dotfiles" means the file is tracked in `tyrcho/dotfiles` and arrives with the clone. Install order is in `Laptop Setup.md`.

## One command covers most installs

`brew bundle --file ~/migration/Brewfile` installs:
- 113 formulas and 18 taps (including `datadog/tap`)
- 24 casks
- 24 Go tools, 18 global npm packages, 2 uv tools, 50 VS Code extensions

Everything below marked **Brewfile** comes from that command.
